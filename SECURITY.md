# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
([direct link](https://github.com/Eshwar1440/autosec/security/advisories/new)).

Don't open a public issue for a security problem. Include what you found, how to
reproduce it, and the impact you expect. You'll get an acknowledgement within a
week.

## Supported versions

Only the latest image published from `main`
(`ghcr.io/eshwar1440/autosec:latest`) receives fixes. Every published image is
signed with cosign and carries SLSA provenance; see the README for how to verify one.
